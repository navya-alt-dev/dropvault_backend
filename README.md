# DropVault - Secure Cloud Storage Platform

A production-ready file storage and sharing application built with React and Django.

## Tech Stack
- **Frontend:** React.js, Context API, Axios
- **Backend:** Django REST Framework, PostgreSQL
- **Storage:** Cloudinary CDN
- **AI:** OpenAI GPT-4 Chatbot
- **Auth:** JWT, Google OAuth, 2FA

## Features
✅ Secure file uploads with duplicate detection  
✅ Share files via email with expiring links  
✅ AI chatbot for intelligent file search  
✅ Real-time notifications  
✅ Trash recovery system  
✅ Mobile-responsive design
